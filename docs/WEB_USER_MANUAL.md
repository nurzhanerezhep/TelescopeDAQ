# TelescopeDAQ Web: руководство пользователя

Версия 0.3. Оборудование: CAEN DT5740D, USB, STANDARD waveform firmware.
Все скриншоты для руководства делайте с пометкой DEMO, если данные синтетические.
В интерфейсе используются английские названия кнопок; ниже приведён порядок работы.

## 1. Запуск сервера

[МЕСТО ДЛЯ СКРИНШОТА №1: терминал с адресом сервера]

--> Строка `TelescopeDAQ: http://127.0.0.1:...` указывает адрес веб-приложения.

В корне проекта откройте PowerShell. При первом использовании выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Обычный запуск:

```powershell
.\.venv\Scripts\python.exe scripts/start_web.py
```

Откройте указанный адрес в Edge, Chrome или Firefox. Начальный порт 8000;
занятый порт заменяется следующим свободным. Терминал оставьте открытым.
Для знакомства без CAEN добавьте `--demo`. DEMO пишет в `output/demo`, показывает
соответствующую метку и не обращается к оборудованию.

## 2. Главная панель и подключение

[МЕСТО ДЛЯ СКРИНШОТА №2: Run Control и верхняя панель]

--> `DAQ Mode` выбирает Full Monitor, Write Only или ROOT Viewer.

--> `Trigger Mode` выбирает Threshold, External или Periodic для следующего run.

--> `Connect` открывает прибор; значок разъединённого штекера выполняет Disconnect.

--> Значок настроек `Configure` открывает Settings.

Закройте WaveDump и другие программы, использующие CAEN. Нажмите Connect.
Дождитесь `connected`, проверьте Model, Serial number и Firmware.
Если возникла ошибка, прочитайте баннер и Logs; приложение не переключится
в симуляцию самостоятельно. Connect не начинает запись и не подаёт триггеры.

## 3. Run ID и параметры записи

[МЕСТО ДЛЯ СКРИНШОТА №3: Settings, разделы Run и CAEN]

--> `Run ID` задаёт номер файла `run_NNNNNN.root`.

--> `Max events` ограничивает число физических событий, не число строк по каналам.

--> `Record length, samples` задаёт запрашиваемую длину waveform.

--> `Pre-trigger, %` и `Group DC offset` задают положение окна и групповое смещение.

Выберите ещё не использованный Run ID. Даже оставшаяся после сбоя копия YAML
с тем же номером блокирует повторную запись. Output directory должен находиться
в папке проекта. Задайте длину записи, процент pre-trigger и offset по условиям
эксперимента. При шаге 16 ns 1024 samples соответствуют 16.384 us.
Значение 196608 является верхней границей валидатора, а не гарантией поддержки
в любой конфигурации памяти; проверьте фактическую длину записанного события.

## 4. Выбор каналов и проверка Settings

[МЕСТО ДЛЯ СКРИНШОТА №4: Channels и сообщение валидации]

--> `Record channels` включает каналы в ROOT-запись.

--> `Signal polarity` задаёт положительные или отрицательные импульсы self-trigger.

--> `Save YAML` сохраняет проверенные настройки; `Reload` отменяет черновик.

--> `Import YAML` загружает черновик; значок скачивания экспортирует сохранённый YAML.

Выберите нужные каналы 0..15; хотя бы один должен оставаться включённым.
Для Threshold обязательно включите ch0. При ошибке поле/сообщение становится
красным, Save и Start блокируются. После исправления дождитесь проверки и
нажмите Save YAML. Параметры записи не изменяются при переключении Full Monitor
на Write Only. Во время записи или scan сохранение заблокировано.

Если другая вкладка или текстовый редактор изменили YAML, нажмите Reload и
повторите правки. Не пытайтесь обходить конфликт revision.
Перед изменением USB link, CONET node или VME address сначала выполните Disconnect.

## 5. Threshold trigger

[МЕСТО ДЛЯ СКРИНШОТА №5: Threshold в Settings и верхний selector]

--> `Threshold, ADC` задаёт абсолютный уровень 0..4095 ADC для ch0.

--> `Trigger Mode: Threshold` включает аппаратный self-trigger от ch0.

Сохраните настройки, выберите Threshold в верхней панели. Порог не является
вычисляемой амплитудой над baseline. Если нет событий, проверьте ch0, знак
сигнала, смещение, выбранный порог и подключение генератора. Не снижайте порог
вслепую при высоком шуме; используйте Threshold Scan.

## 6. External trigger

[МЕСТО ДЛЯ СКРИНШОТА №6: External / TRG-IN в Settings]

--> `Logic level` выбирает NIM либо TTL.

--> `Edge: rising` соответствует поддерживаемому ведущему фронту TRG-IN.

--> `Trigger Mode: External / TRG-IN` переключает источник регистрации.

Остановите run. Согласуйте электрические уровни и форму импульсов внешнего
источника с руководством установленного DT5740D, затем подключите TRG-IN.
Выберите NIM/TTL и оставьте Record enabled channels включённым. Falling
и выборочная запись, противоречащая enabled channels, отклоняются.
Сохраните YAML, выберите External и начните короткий проверочный run.
Во время настройки сервер проверяет обратным чтением режим и IO level.

Новая реализация TRG-IN ещё не проверена физическими импульсами на стенде.
Успешный DEMO-тест этого не подтверждает: в DEMO External событий намеренно нет.
Сначала проверьте небольшой run и полученные waveform, затем длительную запись.

## 7. Periodic trigger

[МЕСТО ДЛЯ СКРИНШОТА №7: Periodic trigger в Settings]

--> `Trigger interval, s` задаёт период программных триггеров.

Выберите положительный период, например 10 s, сохраните YAML и выберите
Periodic в верхней панели. После Start Run первый триггер ожидается после
первого периода. Режим полезен для периодической записи фоновой waveform.
Он не вычисляет baseline и не обеспечивает жёсткую точность аппаратного таймера.

## 8. Начало run и чтение статистики

[МЕСТО ДЛЯ СКРИНШОТА №8: работающий Run Control]

--> `Start Run` применяет сохранённые параметры и начинает ROOT-запись.

--> `Accepted events` считает физические события.

--> `Written waveforms` считает сохранённые waveform отдельных каналов.

--> Полоса прогресса показывает долю Accepted events от Max events.

Проверьте режимы и номер run, затем нажмите Start Run. Можно запускать без
предварительного Connect: приложение откроет CAEN самостоятельно.
Следите за elapsed, размером файла, свободным диском, timestamp и ошибками.
При 16 каналах 100 событий обычно дают 1600 waveform-записей. Written обновляется
после сброса буфера; небольшое отставание во время работы нормально.

Поле Events / N s и график используют реально прочитанные события в скользящем
интервале N секунд. Это не заданная частота генератора. N задаётся в Settings,
Monitor, Event count window. График имеет фиксированное окно последних 30 минут.

## 9. Online Waveform

[МЕСТО ДЛЯ СКРИНШОТА №9: несколько каналов на waveform-графике]

--> Флажки `ch0`...`ch15` выбирают только отображаемые каналы.

--> `Auto scale` меняет масштаб Y; без него используется диапазон ADC 0..4095.

--> `Threshold` показывает линию порога ch0.

--> `Pause display` приостанавливает экран, не запись ROOT.

--> Значок скачивания экспортирует текущий canvas в PNG.

В Full Monitor откройте отдельную вкладку Online Waveform. Выберите один или
несколько каналов. Под графиком указаны event ID, timestamp и исходная длина.
Поле Display sampled предупреждает, что показаны не все события.
Display holdoff задаётся в Settings, Monitor. Более длинная пауза уменьшает
нагрузку; она не добавляет преднамеренной паузы между событиями ROOT.
Длинные waveform прореживаются только для экрана с сохранением пиков.

## 10. Write Only для длительной регистрации

[МЕСТО ДЛЯ СКРИНШОТА №10: компактный Run Control в Write Only]

--> `DAQ Mode: Write Only` отключает online-графику и подготовку preview.

Остановите предыдущий run, назначьте новый номер, сохраните Settings и выберите
Write Only. Запустите запись. Формат данных и аппаратные параметры остаются теми
же, что в Full Monitor. Ориентируйтесь на числовой статус, размер ROOT и Logs.
Закрытие браузера не завершает run: сервер продолжает работать в терминале.

## 11. Threshold Scan

[МЕСТО ДЛЯ СКРИНШОТА №11: окно сканирования с результатом]

--> `Threshold Scan` открывает отдельное окно проверки ch0.

--> `Lower`, `Upper`, `Step` задают диапазон и шаг в ADC.

--> `Time / point` и `Max events / point` задают пределы измерения одной точки.

--> `Start Scan` запускает проверку; `Stop` сохраняет частичный результат.

Остановите run. Задайте диапазон, шаг и одинаковое время измерения точек.
На графике X означает threshold, Y количество физических срабатываний.
Если Max events достигается раньше времени, counts разных точек получены
при разной длительности; используйте rate_hz в CSV для сравнения скорости.
Scan не записывает ROOT и не может работать одновременно с acquisition.

Нажмите на точку графика или введите Selected threshold вручную. Use in Settings
переносит значение в черновик. Проверьте его и нажмите Save YAML.
CSV экспортирует threshold_adc, events и rate_hz. Закрытие окна scan само по
себе не останавливает измерение; используйте Stop.

## 12. Offline ROOT Viewer

[МЕСТО ДЛЯ СКРИНШОТА №12: файл, waveform и временное распределение]

--> `ROOT Viewer` открывает просмотр ранее записанного файла.

--> `Open` читает выбранный файл; значок обновления перечитывает список.

--> `Upload ROOT` импортирует внешний файл, показывая прогресс загрузки.

--> `Entry`, стрелки и `Show` выбирают waveform-запись; `Download` скачивает файл.

Выберите закрытый ROOT из списка. Entry является индексом строки канала с нуля,
а не физическим event ID: одно событие может занимать 16 строк.
Просмотрщик показывает waveform, канал, timestamp и число samples, а также
распределение физических событий по относительным timestamp ticks.
Это не спектр амплитуд и не подтверждённая аппаратная шкала секунд.

Загрузка ограничена 512 MiB; большие файлы поместите в output и обновите список.
Просмотр старого файла разрешён во время нового run и не управляет CAEN.
Текущий записываемый ROOT недоступен до закрытия. Тяжёлый анализ всё равно
использует CPU/диск компьютера, поэтому при предельной скорости его лучше отложить.

## 13. Ошибки, остановка и завершение

[МЕСТО ДЛЯ СКРИНШОТА №13: Logs и кнопки остановки]

--> `Logs` содержит сообщения программы, фильтр ошибок и экспорт журнала.

--> `Stop` запрашивает завершение acquisition и закрытие ROOT.

--> `Emergency Stop` немедленно отправляет запрос остановки без диалога подтверждения.

--> `Disconnect` освобождает USB handle, когда прибор не занят.

При ошибке прочитайте баннер и журнал. Дождитесь завершения операции, устраните
причину и используйте новый Run ID. Приложение не удаляет частичный ROOT после
сбоя и не гарантирует его восстановление.

Emergency Stop не является аппаратной аварийной защитой и не прерывает зависший
вызов драйвера. Он использует корректное завершение writer. Stop сохраняет уже
принятые события, но не гарантирует считывание оставшихся данных памяти прибора.

Для полного завершения сначала нажмите Stop и дождитесь закрытия run, затем
Ctrl+C в терминале сервера. Не завершайте процесс принудительно без необходимости.
Журнал `logs/web.log` ротируется, а ROOT и копия настроек остаются в output.

## 14. Несколько вкладок и доступ

[МЕСТО ДЛЯ СКРИНШОТА №14: общий статус run в двух вкладках]

--> Статус run общий для всех вкладок одного сервера.

Не запускайте параллельные CLI/Tk GUI для того же CAEN. Не используйте несколько
Uvicorn workers или reload. Панель предназначена только для localhost, не имеет
пользовательской авторизации для удалённой сети и не должна публиковаться в Интернет.
